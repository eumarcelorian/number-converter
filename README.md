# Number Converter

A simple Java command-line application that converts numbers between different numeral systems.

## Description

This application allows users to convert numbers between binary, octal, decimal, and hexadecimal formats through an interactive menu. The program runs in a loop, enabling multiple conversions without restarting.

## Features

- Conversion between:
  - Binary
  - Octal
  - Decimal
  - Hexadecimal
- Interactive command-line interface
- Continuous execution using a loop
- Input validation for menu options

## Technologies

- Java
- Scanner (for user input)
- Control structures (if, switch, loops)

## How to Run

1. Clone the repository: git clone https://github.com/your-username/number-converter.git
2. Navigate to the project directory: cd number-converter
3. Compile the program: javac Converter.java
4. Run the application: Java Converter

## Usage

After running the program, choose the input number system from the menu, enter the value, and select the target system for conversion.

Example:

—THE CONVERTER—

1 - BINARY
2 - OCTAL
3 - DECIMAL
4 - HEXADECIMAL
0 - EXIT
```
1
```
Enter a number: 1010

Binary to…
1 - OCTAL
2 - DECIMAL
3 - HEXADECIMAL
```
2
```
